# Phase 1 Data Model: Landing Page Design Polish

**N/A — no data entities.** This feature is a presentation-only change to a
static page (spacing, proportions, letter-spacing, and text punctuation); it
does not introduce, modify, or remove any data, content model, or state.

The closest analog to "entities" here are the CSS design values this
feature changes. They are fully enumerated as the implementation contract
in [`contracts/style-changes.md`](./contracts/style-changes.md) rather than
duplicated here, since there is no separate data shape to model beyond
those CSS property values.
